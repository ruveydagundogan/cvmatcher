# LLM Decision Score

**AI-powered decision scoring using WebLLM (Gemma) and Go Backend**

</div>

---

## Overview

LLM Decision Score is a full-stack AI application that runs **Gemma locally in the browser using WebLLM** and evaluates each response with a Go backend to generate a decision score.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Go
- Gin
- WebLLM (Gemma)

## Project Structure

```text
frontend/    Next.js application
backend/     Go REST API
```
